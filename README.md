# Daily-Expense-Tracker
The Daily Expense Tracker is a lightweight Python project designed to help users monitor their day-to-day spending. It allows users to add expenses, categorize them (e.g., food, travel, shopping), view daily/monthly reports, and analyze their spending habits.
The main goal of this project is to demonstrate core Python concepts such as data structures, object-oriented programming, file/database handling, input validation, and basic analytics.
